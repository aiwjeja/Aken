# 🌿🐾 Plant & Animal AI Analysis Backend

Backend AI untuk menganalisa gambar **tumbuhan dan hewan** menggunakan **Google Gemini Vision API**.  
Dirancang menggunakan **Vercel Serverless Functions (Node.js)** agar ringan, cepat, dan mudah di-deploy.

---

## 🚀 Fitur Utama

- Analisa tumbuhan secara mendetail  
- Analisa hewan secara mendetail  
- Deteksi kondisi kesehatan  
- Persentase kesehatan (0–100%)  
- Rekomendasi perawatan & solusi  
- Siap untuk integrasi frontend apapun  
- Serverless & hemat resource
